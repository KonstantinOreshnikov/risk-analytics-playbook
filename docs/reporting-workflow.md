# Controlled Reporting Workflow

## 1. Frame the decision

State the management question, intended audience, reporting frequency and action expected from the output.

## 2. Lock the metric contract

Confirm population, grain, numerator, denominator, time logic, exclusions and maturity.

## 3. Inspect the source

Verify field availability and types before designing joins or calculations. Never assume a field exists because a similar source contains it.

## 4. Protect the baseline

Capture the current successful result and its control totals. Apply the smallest necessary change before attempting optimization.

## 5. Transform transparently

Keep extraction, business rules, aggregation and presentation fields identifiable. Use short comments for material logic.

## 6. Reconcile

Compare row counts, distinct keys, dates and key measures with the baseline and an authoritative control source.

## 7. Build the output

Choose a table or chart based on the decision, not decoration. Preserve meaningful scale and show the latest value, significant break and relevant comparison.

## 8. Review commentary

Separate observed facts, likely drivers, uncertainty and recommended action.

## 9. Release and version

Record the data period, code version, definition version, refresh time and known limitations.
